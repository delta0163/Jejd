3. Песни и персонажи

Пока используем стандартные персонажи. Для собственных Дельты и Хака позднее добавим спрайты и character JSON.

4. Иконки персонажей

Загрузи PNG-изображения иконок. Они попадут в архив мода.

Пока это будут файлы ресурсов. Чтобы они появились во время боя, их нужно будет связать с персонажами в их настройках.

5. Редактор чартов

Выбери песню, загрузи аудио, включи воспроизведение и нажимай на дорожки, чтобы расставлять ноты.

Сетка показывает примерно 8 секунд музыки. Текущее время аудио находится внизу шкалы.

Игрок: дорожки 1–4. Соперник: дорожки 5–8. Нажатие на уже существующую ноту удаляет её.

6. Сборка мода

Добавь аудио для каждой песни. Если чарт уже создан, загрузи его JSON сюда. Если не загрузишь, сайт использует чарт из редактора.
